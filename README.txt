STUDENT MARKS PREDICTION - AI/ML PROJECT

Files:
1. student_marks_dataset.csv - training dataset
2. student_marks_predictor.py - Tkinter GUI + ML model
3. requirements.txt - Python packages
4. Student_Marks_Prediction_Project_Report.docx - project report
5. Student_Marks_Prediction_Project_PPT.pptx - presentation
6. Viva_Questions_and_Answers.txt - viva preparation

How to run:
1. Put all files in the same folder.
2. Install Python 3.
3. Open terminal in this folder.
4. Run: pip install -r requirements.txt
5. Run: python student_marks_predictor.py

Note: tkinter is normally included with standard Python on Windows/macOS. On some Linux distributions it may need a system package.
